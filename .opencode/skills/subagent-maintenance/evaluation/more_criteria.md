# More Criteria（推奨修正）

## 内容チェック（スコアリング）

品質向上のための改善提案。未修正でも合格可能。

| 観点 | 評価基準 | 配点 |
|------|----------|------|
| description品質 | 自動委譲のトリガーとして具体的なユースケースを含む | 30 |
| skills連携 | skillsフィールドとSkill側のSubagent Executionセクションが整合している | 25 |
| 単一責任原則 | 1エージェント1専門領域を守っている | 25 |
| 追跡可能性 | 変更理由・変更ログが明記されている | 20 |

**合計**: 100点

## 推奨項目一覧

### description品質向上
- [ ] 自動委譲のトリガーとして具体的なユースケースを含む
- [ ] 専門領域が明確に記載されている
- [ ] 委譲条件が具体的に記載されている
- [ ] 期待される出力が明確

### skills連携向上
- [ ] skillsフィールドとSkill側のSubagent Executionセクションが整合している
- [ ] 参照先Skillが実在する
- [ ] Skill側でSubagentが適切に呼び出される
- [ ] データ受け渡しが明確

### 単一責任原則向上
- [ ] 1エージェントが1つの専門領域のみ担当している
- [ ] 領域の境界が明確
- [ ] 他エージェントとの重複がない
- [ ] 責任範囲が過大でない

### 追跡可能性向上
- [ ] 変更理由が明記されている
- [ ] 変更ログが記載されている
- [ ] バージョン情報が管理されている
- [ ] 前回との差分が追跡できる

## 許容例外（More対象）

以下は修正推奨だが、未修正でも合格可能。

- 新規作成時は「既存機能維持」チェック対象外
- model指定は省略可（親から継承）
- 文字数制限（5,000語以内）は推奨事項

## Good（保持項目）

評価時に特に優れていた点を記録し、次回も維持する。

```markdown
### Goodポイント
- [ ] 明確な専門領域の定義
- [ ] 効果的な自動委譲トリガー
- [ ] 適切なSkill連携設計
```
