# X Automation - Most Criteria（必須修正）

## 評価方針

**Most** = 致命的欠損や構造的問題。未修正時は成果物を確定できない。

**判定**: 各項目を Pass/Fail で評価。Failがある場合は修正必須。

---

## 必須チェック項目

### 1. テンプレート準拠
**基準**: 必須セクション（Instructions/Resources/Next Action）が存在する

- [ ] **Pass**: 必須セクション（Instructions/Resources/Next Action）が全て存在する
- [ ] **Fail**: 必須セクションが欠落している

**判定**: [ ]

---

### 2. 必須セクション維持
**基準**: 既存Skillの必須セクション区切りが崩れていない

- [ ] **Pass**: 既存のセクション区切りが維持されている
- [ ] **Fail**: セクション区切りが崩れている

**判定**: [ ]

---

### 3. 推測禁止
**基準**: 不明項目は「未記載」「不明」と明記されている

- [ ] **Pass**: 不明項目は「未記載」「不明」と明記されている
- [ ] **Fail**: 推測で内容を補完している

**判定**: [ ]

---

### 4. questionsファイル存在
**基準**: questions/{name}_questions.md が存在する

- [ ] **Pass**: questionsファイルが存在する
- [ ] **Fail**: questionsファイルが存在しない

**判定**: [ ]

---

### 5. evaluationファイル存在
**基準**: evaluation/evaluation_criteria.md が存在する

- [ ] **Pass**: evaluationファイルが存在する
- [ ] **Fail**: evaluationファイルが存在しない

**判定**: [ ]

---

## 総合判定

| 項目 | 判定 |
|------|------|
| テンプレート準拠 | [ ] |
| 必須セクション維持 | [ ] |
| 推測禁止 | [ ] |
| questionsファイル存在 | [ ] |
| evaluationファイル存在 | [ ] |

**Most判定**: [ ] **全Pass** / [ ] **Failあり（修正必須）**

---

## 修正指示

### Fail項目がある場合
1. 該当項目を特定
2. 問題の詳細を記録
3. 修正方針を決定
4. 修正実施
5. 再評価

### 修正記録フォーマット
```
- [ ] [項目名]: [問題の詳細]
  - 修正内容: [具体的な修正]
  - 修正者: [名前]
  - 修正日: [日付]
```
