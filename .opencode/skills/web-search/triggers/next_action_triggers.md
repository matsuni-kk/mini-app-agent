# web-search Next Action Triggers

## 自動実行ルール
以下の条件を満たす場合は、該当Skillの実行を検討する（WF自動継続）。

## 起動条件テーブル

| ID | 起動条件 | 実行Skill | 優先度 | 備考 |
|----|---------|-----------|--------|------|
| T1 | 依頼文に「顧客」または「Customer」が含まれる | `pmbok-customer-research` | 2 | Web検索結果を材料に顧客調査へ展開 |
| T2 | 依頼文に「競合」または「Competitor」が含まれる | `pmbok-competitor-research` | 2 | Web検索結果を材料に競合調査へ展開 |
| T3 | 上記に該当せず、継続調査が必要 | `pmbok-desk-research` | 3 | 総合レポートへ統合 |

## スキップ条件
- ユーザーが明示的に「Web検索のみ」と指定した場合

## 条件判定ロジック
1. Skill完了時、起動条件テーブルを上から順に評価する
2. 条件を満たす行があれば、スキップ条件を確認する
3. スキップ条件に該当しなければ、該当Skillを実行する
