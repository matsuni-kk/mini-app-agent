# More（採点項目）- 100点満点

More項目は品質の程度を測定するスコアリング項目です。配点合計は100点です。

## 採点基準

| 観点 | 評価基準 | 配点 |
|------|----------|------|
| 配布成功率 | 成功数/対象数 × 30点 | 30 |
| ファイル完全性 | 必須ファイル（SKILL.md, questions/, assets/, evaluation/）が存在 | 25 |
| モード適用 | 指定モード（overwrite/new_only）が正しく適用されている | 25 |
| レポート品質 | 配布結果が正確に報告されている | 20 |
| エラーハンドリング | エラー発生時の適切な処理と回復 | 20 |

## 詳細評価基準

### 配布成功率（30点）

| スコア | 基準 |
|--------|------|
| 30点 | 成功率100% |
| 24-29点 | 成功率80-99% |
| 18-23点 | 成功率60-79% |
| 12-17点 | 成功率40-59% |
| 0-11点 | 成功率40%未満 |

### ファイル完全性（25点）

| 項目 | 配点 |
|------|------|
| SKILL.md存在 | 10点 |
| questions/ディレクトリ | 5点 |
| assets/ディレクトリ | 5点 |
| evaluation/ディレクトリ | 5点 |

### モード適用（25点）

| モード | 評価基準 |
|--------|----------|
| overwrite | 既存ファイルが上書きされている |
| new_only | 既存フォルダはスキップされ、新規のみ配布されている |

| スコア | 基準 |
|--------|------|
| 25点 | 全配布先でモードが正しく適用されている |
| 20点 | 90%以上で正しく適用されている |
| 15点 | 80%以上で正しく適用されている |
| 10点 | 60%以上で正しく適用されている |
| 0-5点 | 60%未満 |

### レポート品質（20点）

| 項目 | 配点 |
|------|------|
| 配布先一覧の正確性 | 5点 |
| 成功/失敗の明確な記録 | 5点 |
| エラー内容の詳細記録 | 5点 |
| サマリー情報の網羅性 | 5点 |

### エラーハンドリング（20点）

| 項目 | 配点 |
|------|------|
| エラー検知の適時性 | 5点 |
| エラーログの詳細性 | 5点 |
| 継続可能性の確保 | 5点 |
| リカバリー手順の明確性 | 5点 |

## 合計スコア計算

```
合計スコア = 配布成功率 + ファイル完全性 + モード適用 + レポート品質 + エラーハンドリング
         = 30 + 25 + 25 + 20 + 20
         = 100点満点
```
