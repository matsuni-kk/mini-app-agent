# skill-maintenance skills 質問事項

このファイルは質問事項の一覧です。

### 操作種別
- **質問**: 操作種別（edit／add。デフォルト: edit）
- **選択肢**:
  - edit
  - add

### 対象Skillフォルダ
- **質問**: 対象Skillフォルダ（既存または作成予定。例: pmbok-agenda）
- **形式**: 自由記述

### 変更範囲
- **質問**: 変更したいセクション・行・トリガー内容（例: Instructions を最新要件へ更新）
- **形式**: 自由記述

### 期待する状態
- **質問**: 適用後にどうなっていてほしいか（成果物／挙動）
- **形式**: 自由記述

### 検証手順
- **質問**: 検証手順（レビュー・動作確認・必要なテストなど）
- **形式**: 自由記述

### 完了までの作業手順
- **質問**: スケルトンを埋める／既存Skillを更新する具体的な作業手順（誰が・いつ・どこまで）
- **形式**: 自由記述

### 変更理由
- **質問**: 変更理由（Why）と根拠資料
- **形式**: 自由記述

### レビュー責任者
- **質問**: レビュー責任者（氏名／ロール）
- **形式**: 自由記述

### レビュー期限
- **質問**: レビュー期限（YYYY-MM-DD）
- **形式**: 自由記述

## 新規作成時の追加質問（operation=add）

### Skill名
- **質問**: operation=add の場合: Skill名（英小文字+ハイフン。例: new-feature-skill）
- **形式**: 自由記述
- **注意**: kebab-case（英小文字+ハイフン）

### Skill説明
- **質問**: operation=add の場合: Skill説明（日本語）
- **形式**: 自由記述

## 任意（入力またはスキップ）

### pathsの追加/修正
- **質問**: paths（master_rules.mdc内のroot/dirs/patterns）を追加／修正する必要がありますか？（具体的なキー名と値）
- **形式**: 自由記述 または `skip`

### ワークフロー索引の更新
- **質問**: CLAUDE.md/AGENTS.md のワークフロー索引を更新しますか？（yes/no と内容）
- **形式**: `yes` / `no` + 詳細

### 差し戻し計画
- **質問**: 差し戻し時の復旧方法・連絡先
- **形式**: 自由記述 または `skip`
