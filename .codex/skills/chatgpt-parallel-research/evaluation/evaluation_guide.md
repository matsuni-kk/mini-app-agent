# ChatGPT Parallel Research 評価ガイド

## 評価レベル定義

### Most（必須修正 - Must Fix）
**定義**: 致命的欠損や構造的問題。未修正時は成果物を確定できない。

**対象ファイル**: `most_criteria.md`

**基準**:
- 並列数要件の未達（3並列以上の検索が実行されていない）
- クエリ多様性の欠如（異なる視点・切り口のクエリが設計されていない）
- 結果統合の欠如（各検索結果が統合分析されていない）
- 推測による記載（元資料にない内容を「未記載」と明記せず推測で記載）

**対応**:
- 未修正項目がある場合は `Fail`
- 修正完了まで成果物を確定しない

### More（推奨修正 - Nice to Have）
**定義**: 品質向上のための改善提案。リソースと優先度で判断可能。

**対象ファイル**: `more_criteria.md`

**基準**:
- 網羅性（調査テーマに対して十分な角度から検索されているか）
- 正確性（情報の信頼性評価がされ、矛盾点が整理されているか）
- 統合力（複数の検索結果が適切に統合・分析されているか）
- 実用性（結論と推奨アクションが具体的で実行可能か）

**対応**:
- 未修正でも `Pass` 可能（記録に留める）
- 時間許容時に実施

### Good（評価・保持項目）
**定義**: 特に優れていた点。次回も維持すべき要素。

**記録場所**: `more_criteria.md` の末尾

**基準**:
- 効果的なクエリ設計
- 優れた検索結果の統合
- 予想外の付加価値

**対応**:
- 次回のタスクでも維持する
- ベストプラクティスとして記録

---

## 採点基準

| 判定 | 条件 |
|------|------|
| **Pass** | 全Most項目がPass かつ Moreスコア80点以上 |
| **Conditional Pass** | 全Most項目がPass かつ Moreスコア60-79点（軽微な修正で確定可） |
| **Fail** | Most項目にFailあり または Moreスコア60点未満 |

---

## QC報告フォーマット

```markdown
### QC結果: [Pass/Conditional Pass/Fail]

#### Most（必須修正）
- [x] 項目名: Pass
- [ ] 項目名: Fail → 修正必須: [具体的な問題]

**判定**: [Most全Pass/MostにFailあり]

#### More（推奨修正）
スコア: [XX]/100

| 観点 | 得点 | コメント |
|------|------|----------|
| [観点名] | [XX]/[配点] | [簡潔な評価] |

#### Good（保持項目）
- [ ] [優れていた点1]
- [ ] [優れていた点2]

#### 指摘事項
1. **[Most/More]** [項目名]: [指摘内容]
   - 影響: [致命的/軽微]
   - 修正案: [具体的な改善案]

#### 推奨対応
- [ ] **Most** #[番号]: [対応アクション]（必須）
- [ ] **More** #[番号]: [対応アクション]（推奨）
```

## 使い方

### Step 1: Mostチェック（生成直後）
```
→ most_criteria.md を開く
→ 各項目を Pass/Fail で判定
→ Failがある場合は即座に修正
```

### Step 2: Moreチェック（Most修正後）
```
→ more_criteria.md を開く
→ スコアリングを実施
→ 80点以上なら Pass判定
→ 60-79点なら Conditional Pass（記録のみ）
→ 60点未満なら改善提案を記録
```

### Step 3: 最終判定
```
→ QC報告フォーマットで結果を記録
→ Most未修正→ Fail
→ Most修正済み + Moreスコアで最終判定
→ Goodポイントを記録して次回に活かす
```

## Most vs More の判断基準

| 観点 | Most | More |
|------|------|------|
| **未修正時の影響** | 成果物確定不可 | 記録に留める |
| **判断の客観性** | 客観的（Pass/Fail） | 主観的含む（スコア） |
| **修正緊急度** | 即座 | 余裕ある時 |
| **例** | 並列数未達、クエリ多様性欠如 | 網羅性、正確性向上 |

## 注意事項

### Mostに含めるべきでないもの
- 表現の好み（「こう書いた方が良い」）
- 付加価値の有無（本来あるべき内容の超過）
- 細部の完璧さ（重要でない詳細）

### Moreに含めるべきでないもの
- 致命的欠損（Mostへ移動）
- 明確な誤り（Mostへ移動）
- テンプレート準拠違反（Mostへ移動）

### 一般的なMost項目（Skill共通）
- [ ] テンプレート準拠（必須セクションの存在）
- [ ] 推測禁止（元資料にない内容は「未記載」と明記）
- [ ] 論理的一貫性（矛盾、飛躍がない）
- [ ] ハルシネーションなし（事実誤認がない）

### 許容例外
- ブリッジサーバー接続エラーによる一時的な並列数減少
- ChatGPTの応答遅延によるタイムアウト（再試行が実施された場合）
- 特定のクエリがテーマに不適合と判断され除外された場合（理由が明記されていること）

## 並列検索の評価基準

### 必須要件
- **最低並列数**: 3並列以上（必須）
- **推奨並列数**: 4-6並列（複雑なテーマの場合）
- **最大並列数**: 10並列程度（それ以上は管理が困難）

### クエリ設計の評価

| 評価 | 基準 |
|------|------|
| 優秀 | 5つ以上の異なる視点、相互補完的なクエリ設計 |
| 良好 | 4つの異なる視点、バランスの取れたクエリ |
| 合格 | 3つの異なる視点、最低限の多角的アプローチ |
| 不合格 | 2つ以下、または類似クエリの重複 |

### モデル選択の評価

| 難易度 | 正しい選択 | 誤った選択（減点） |
|--------|------------|-------------------|
| 簡単 | gpt-4o | o3 + heavy（過剰） |
| 普通 | gpt-4o | gpt-4o-mini（品質不足） |
| 難問 | o3 + standard/heavy | gpt-4o（精度不足） |
| 最難関 | o3 + extended | o3 + light（精度不足） |

## 追加検索のトリガー

以下の場合は追加の並列検索を推奨：

1. **情報不足**: 特定の観点が十分にカバーされていない
2. **矛盾発見**: 検索結果間で矛盾があり、追加調査が必要
3. **深掘り必要**: 発見した情報をさらに詳しく調査する必要がある
4. **最新情報不足**: 得られた情報が古い可能性がある
