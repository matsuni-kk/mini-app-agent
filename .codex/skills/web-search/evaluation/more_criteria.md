# More Criteria（推奨修正）

## 内容チェック（スコアリング）

品質向上のための改善提案。未修正でも合格可能。

| 観点 | 評価基準 | 配点 |
|------|----------|------|
| 正確性 | 推測混入がなく、出典に基づいている | 40 |
| 網羅性 | 指定された観点・範囲が扱われている | 25 |
| 明瞭性 | 読み手が解釈に迷いにくい | 20 |
| 実行可能性 | 次アクションが具体で実行可能 | 15 |

**合計**: 100点

## 推奨項目一覧

### 正確性向上
- [ ] 一次情報と二次情報の区別
- [ ] 情報の鮮度（発行日・更新日）の明示
- [ ] 情報源の信頼性評価
- [ ] 複数情報源の比較検証

### 網羅性向上
- [ ] 指定観点の全網羅
- [ ] 関連情報のクロスリファレンス
- [ ] エッジケースの考慮
- [ ] 複数視点（肯定/否定/中立）の提示

### 明瞭性向上
- [ ] 構造化された情報整理
- [ ] 重要度・信頼度の明示
- [ ] 専門用語の注釈
- [ ] 結論と根拠の明確な区別

### 実行可能性向上
- [ ] 次アクションの具体化
- [ ] 確認事項の明確化
- [ ] 意思決定論点の提示
- [ ] 追加調査の優先順位付け

## 許容例外（More対象）

以下は修正推奨だが、未修正でも合格可能。

- 一般的常識には出典を省略可
- 複数情報源が同じ結論の場合、代表例のみ記載可
- 軽微な表現の違い（事実に影響なし）

## Good（保持項目）

評価時に特に優れていた点を記録し、次回も維持する。

```markdown
### Goodポイント
- [ ] 多角的視点での情報収集
- [ ] 情報の信頼性評価
- [ ] 構造化された情報整理
```
